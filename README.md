## Genel Bakış

Fynext, yerel ortamda çalışan gelişmiş bir yapay zeka ajanıdır. Kod analizi, proje yönetimi ve geliştirme süreçlerini otomatikleştirmek üzere tasarlanmıştır.

Bilgisayarınızda güvenli bir şekilde çalışan, açık kaynaklı bir çözümdür.

## Özellikler

| Özellik | Açıklama |
| :-- | :-- |
| **Akıllı Kod Analizi** | Kod tabanınızı analiz eder ve iyileştirme önerileri sunar. |
| **Proje Yönetimi** | Proje dosya yapısını anlar ve organize eder. |
| **Yerel Çalışma** | Tüm işlemler yerel ortamda gerçekleşir; verileriniz hiçbir zaman dışarı çıkmaz. |
| **Hızlı İşlem** | Optimize edilmiş performans sayesinde hızlı çalışır. |
| **Hedefli Çözümler** | Belirli görevlere göre özelleştirilebilir. |

## Başlangıç

### Gereksinimler

| Bileşen | Sürüm | Durum |
| :-- | :-- | :-- |
| İşletim sistemi | Windows, Linux veya macOS | Gerekli |
| Node.js | 16 veya üzeri | Gerekli (npm ile kurulum için) |
| Python | 3.8 veya üzeri | İsteğe bağlı |

### Kurulum

Fynext’i npm üzerinden global olarak yükleyin:

```bash
npm install -g github:firexystudio-lang/Fynext
```

### Termux Üzerinde Çalıştırma (Deneysel)

> [!WARNING]
> **Meraklı Termux kullanıcıları için uyarı**
>
> Gerekli tüm paketler sağlandığında Fynext, Termux üzerinde sorunsuz biçimde başlatılabilmektedir; bu durum geliştirici tarafından denenmiştir. Ancak amiral gemisi sınıfında olmayan cihazlarda telefonun tamamen donduğu ve sistem arayüzünün yanıt vermediği gözlemlenmiştir.
>
> Bu yöntem deneyseldir. Denemeden önce açık çalışmalarınızı kaydetmeniz ve arka plandaki uygulamaları kapatmanız önerilir.

## Katkıda Bulunma

Katkılarınız bizim için çok değerlidir. Hata bildirimleri ve önerileriniz için **Issues** bölümünü kullanabilir, geliştirme katkıları için aşağıdaki adımları izleyebilirsiniz:

1. Depoyu **fork** edin.
2. Yeni bir özellik dalı oluşturun:

   ```bash
   git checkout -b feature/ozellik-adi
   ```

3. Değişikliklerinizi **commit** edin:

   ```bash
   git commit -m "Kısa ve açıklayıcı commit mesajı"
   ```

4. Dalınızı uzak depoya **push** edin:

   ```bash
   git push origin feature/ozellik-adi
   ```

5. GitHub üzerinden bir **Pull Request** açın.
