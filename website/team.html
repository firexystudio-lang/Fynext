## katkı

birlikte daha iyi

Katkılarınız çok değerli. Hata bildirimleri ve öneriler için GitHub Issues bölümünü kullanın. Kod katkısı için aşağıdaki adımları izleyin.

  • Depoyu fork'layın ve özellik dalı oluşturun.
  • Değişikliklerinizi kısa ve açıklayıcı bir mesajla commit'leyin.
  • Dalınızı push'layın ve bir Pull Request açın.
  • npm test ile test paketini çalıştırın.
hızlı katkı akışı
bash
# 1) fork'tan klonlayın
git clone https://github.com/<kullanici>/Fynext.git
cd Fynext

# 2) özellik dalı açın
git checkout -b feature/yeni-ozellik

# 3) geliştirin ve test edin
npm install
npm test

# 4) commit ve push
git commit -m "Kısa ve açıklayıcı mesaj"
git push origin feature/yeni-ozellik
pull request
