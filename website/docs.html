hızlı başlangıç

Fynext, terminalde çalışan yerel bir yapay zekâ kod ajanıdır. Kurulum için Node.js 20 veya üzeri gerekir.

terminal
# 1) global kurulum
npm install -g github:firexystudio-lang/Fynext

# 2) proje kökünde başlat
cd ~/projects/app
fynext

İlk çalıştırmada Fynext sizi karşılar ve tercihleri sorar. Ardından Lumen motoruna geçip model seçebilirsiniz:

fynext
/engine lumen
/models
/model gemma-4-e2b-it-q4_0
  • Proje kökünde .fynext/project-memory.json oluşturulur ve çalışma alanı indekslenir.
  • Bağlamı azaltmak için /compact, dışa aktarmak için /export kullanın.
  • Yardım için /help yazın veya Ctrl+P ile komut paletini açın.

motorlar

Fynext iki yerel çıkarım motoru sunar. Varsayılan motor Ollama'dır; Lumen ise llama.cpp tabanlı gömülü bir alternatiftir.

motoraçıklamakomut
OllamaYerel Ollama sunucusundaki modellerle çalışır. Daha büyük modeller için idealdir./engine ollama
LumenGGUF modellerini doğrudan llama.cpp ile çalıştırır. Ollama gerekmez./engine lumen
GPULumen için GPU kullanımını gösterir veya ayarlar./gpu auto | cpu

/gpu cpu seçeneği daha yavaştır ancak bazı sistemlerde daha kararlıdır. Lumen, GPU'yu otomatik algılar ve gerekirse CPU'ya geri döner.

modeller

Model kataloğuna /models ile erişin. Fynext indirme öncesi onay ister, her GGUF dosyasının SHA-256 değerini doğrular ve kesilen indirmeleri sürdürebilir.

modelboyutnot
gemma-4-e2b-it-q4_0~2.65 GiBVarsayılan. Dengeli kalite ve hız.
qwen2.5-coder-1.5b-q4_k_m~1.04 GiBKompakt, düşük bellek.
qwen2.5-coder-1.5b-q5_k_m~1.20 GiBDaha yüksek kalite, hâlâ kompakt.

Modeller kullanıcı yapılandırma dizinindeki models/lumen klasöründe saklanır. Farklı bir konum için FYNEXT_MODEL_DIR ortam değişkenini kullanın. Gemma 4 Apache-2.0 lisansı altındadır.

model seçimi
Kompakt modeller hızlıdır ancak karmaşık görevlerde daha büyük Ollama modelleri daha iyi sonuç verebilir. Donanımınıza göre denge kurun.

slash komutları

Komutları doğrudan yazın veya Ctrl+P / Ctrl+N ile komut paletinden seçin.

iş akışları

Sık kullanılan mühendislik görevleri için hazır akışlar:

  • İnceleme ve risk kontrolü: /project → /review → /git
  • İnşa ve doğrulama: /mode build → npm test → npm run build
  • Değişiklik özeti: /git → git log --oneline -10 → özetle
  • PR özeti: /project → /git → değişen dosyaları incele → etkiyi özetle
fynext
# plan modunda güvenli analiz
/plan Kimlik doğrulama katmanını incele ve riskleri listele

# onaydan sonra inşa modu
/mode build Oturum yenileme akışını düzelt

# değişiklikleri gözden geçir
/diff
/undo   # gerekirse son değişikliği geri al

proje yapısı

Fynext kaynak kodu sorumluluklarına göre düzenlenmiştir:

depo
bin/            CLI giriş noktası
src/cli/        ana orkestrasyon ve TUI bağlantısı
src/agent/      niyet yönlendirme ve araç durumu
src/ai/         Ollama istemcisi ve araç çağrısı ayrıştırma
src/tools/      dosya sistemi, git, web ve shell araçları

src/history/    sohbet geçmişi ve değişiklik takibi
src/ui/         ekran, tema, metin yardımcıları
src/config/     varsayılanlar ve ayar kalıcılığı
src/setup/      ilk çalıştırma kurulumu
src/workflow/   özellik yol haritası ve iş akışı hazır ayarları
test/           node:test paketleri ve fikstürler
config/         sistem istemi ve kullanıcı ayarları

sorun giderme

  • Node sürümü hatası: node --version çıktısının 20 veya üzeri olduğundan emin olun.
  • Model indirilemiyor: Bağlantıyı kontrol edin; Fynext kesilen indirmeleri sürdürebilir. Gerekirse FYNEXT_MODEL_DIR ile farklı bir konum seçin.
  • GPU kararsızlığı: Lumen için /gpu cpu ile CPU moduna geçin.
  • ESP32 bağlanmıyor: /face ports ile portu doğrulayın ve doğru portu /face port ile seçin.
  • Termux donması: Deneysel destek sınırlıdır. Açık işlerinizi kaydedin ve arka plan uygulamalarını kapatın.
